# Tables

This directory contains the numerical outputs generated by the analysis notebook.

## Contents

The CSV files include:

- PCA explained variance by component;
- cumulative explained variance;
- number of principal components required to reach selected variance thresholds;
- Adjusted Rand Index (ARI) across PCA dimensionalities;
- class-level F1-scores across PCA dimensionalities;
- maximum F1-score achieved by each taxonomic class;
- PCA dimensionality associated with each maximum F1-score;
- first PCA dimensionality at which selected F1 recovery thresholds are reached;
- class-level recovery summaries.

These files are generated automatically when the main notebook is executed.
