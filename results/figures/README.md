# Figures

This directory contains the figures generated by the analysis notebook and used in the associated study.

## Contents

The figures include:

- taxonomic class distributions;
- cumulative explained variance;
- global ARI across PCA dimensionalities;
- class-level F1-score heatmaps;
- maximum F1-score by taxonomic class;
- distribution of class recoverability;
- PCA dimensionality required to reach selected recovery thresholds;
- classes reaching F1 ≥ 0.60;
- relationship between class size and maximum F1-score;
- PC1--PC2 projections;
- PCA loading profiles.

Figures are provided in PNG and/or PDF format.

PDF files are recommended for inclusion in LaTeX documents because they preserve vector quality when scaled.
